*   **三大核心知識點 (Core Takeaways)**:
    1.  **MCP (Model Context Protocol) 運作原理**：透過 `nlm` CLI 工具作為翻譯官，讓 Claude 能模擬瀏覽器登入及點擊操作，在沒有官方 API 的情況下對 NotebookLM 進行自動化控制。
    2.  **自動化環境建置**：藉由拖入 Markdown 懶人包，AI 可自動檢測並安裝所需的工具（如 uv、mcp cli、git），降低新手設定門檻。
    3.  **自動檔案分類儲存**：自動在本機建立 8 個分類資料夾（簡報、資訊圖表、音訊、概覽、Google文件、試算表、心智圖、測驗閃卡），讓產出的教材歸類有條不紊。

### 2. Claude基本功EP04 _ NotebookLM 進階應用五大情境_跨工具神操作：從 NotebookLM 自動同步到 Obsidian 與 GitHub
*   **一句話精華**: 展示如何將 Claude Desktop 連接 NotebookLM 後，應用於自動化、定時化、行動化、串聯化及規模化五大情境，實現跨工具（如 Obsidian、GitHub）神操作與備課效能最大化。
*   **三大核心知識點 (Core Takeaways)**:
    1.  **五大應用維度 (五大化)**：
        *   *自動化*：多步驟備課（產出簡報、Bloom差異化教材、測驗等）。
        *   *定時化*：使用排程結合 Deep Research 定期追蹤最新教育趨勢。
        *   *行動化*：利用手機版 Claude 的 Dispatch 功能遠端傳送語音指令給本機執行。
        *   *串聯化*：跨工具同步，如把報告存到 Obsidian，將簡報傳上 GitHub。
        *   *規模化*：批次整理評估 100+ 本筆記活躍度並重新命名。
    2.  **備課技能 (Skill) 封裝**：將一整套教材生成 SOP（包含 Bloom 認知層次的記憶/理解/應用/分析教材與 10 題測驗，並轉成試算表與 Word）打包成全域檔案型 Skill。
    3.  **容量優化與 mcp 控制**：因 GitHub Pages 具備單檔與全站流量限制，透過 AI 將 PDF 簡報轉成 1080p JPG 圖片以節省容量；提醒使用者勿安裝過多無用 MCP 以免占用 token 上下文。
*   **涉及的 AI 軟體 / 工作流工具**: Claude Desktop / Claude Code, NotebookLM, Obsidian, GitHub, Claude Dispatch (手機版), UV / CLI 整合。
