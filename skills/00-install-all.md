# 一次安裝全部技能

依序載入並執行：

1. **01-notebooklm** — 連接 NotebookLM
2. **02-github** — 連接 GitHub
3. **03-firebase** — 連接 Firebase
4. **04-draw** — 生圖指引
5. **05-workflow** — 開工 / 收工 / 新專案初始化
6. **06-obsidian** — Obsidian 筆記工作流（免 MCPVault）
7. **07-coffee** — 咖啡職人自動化工作流
