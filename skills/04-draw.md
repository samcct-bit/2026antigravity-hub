# 生圖（AntiGravity 內建版）

本指南說「生圖」、「畫圖」、「產生圖片」時載入。

## 💡 免安裝說明

在 **Anti-Gravity** 環境中，**不需要**進行任何額外的安裝或套件設定！
本系統已內建了專用的 `generate_image` 工具，可以直接使用自然語言下達指令產生圖片，**不需要**配置任何 OpenAI API key，更不需要將金鑰寫入專案或儲存庫中。

## 建議提示格式

當需要生成圖片時，請遵守以下提示格式：

```text
生成一張圖片：
用途：[例如：網頁背景、產品插圖、按鈕圖示]
尺寸比例：[例如：1:1, 16:9, 9:16]
主題：[描述主體事物]
畫面內容：[具體的人物、場景、元素描述]
風格：[例如：現代極簡、3D 渲染、手繪風、玻璃擬態]
色彩：[色調或配色方案]
文字：[若有，要出現在圖片中的文字內容]
限制：[避免出現的事物]
輸出位置：[指定的實體路徑，例如 d:/2026antigravity/assets/xxx.png]
```

## ⚠️ 重要注意事項

1. **中文出字錯誤**：圖片中若需要重要的中文文字，建議通過圖像後製軟體加上，因為 AI 生圖模型可能會產生拼寫或出字錯誤。
2. **圖片儲存位置**：專案中引用的所有圖片，請務必存放在專案的 `assets/` 目錄或經使用者確認的素材資料夾中。
3. **避免提交髒檔案**：請勿將任何臨時生成的測試圖片 commit 或 push 到公開/懶人包的 Git 儲存庫中。
