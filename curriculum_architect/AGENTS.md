# 108課綱教案設計工作區 (curriculum_architect)

一條「給單元與目標 → 逆向設計處理 → 輸出課綱定位與 GRASPS 評量架構」的可重複工作流。

## 固定偏好
- 角色：108 課綱教案架構師。
- 逆向設計：一律先規劃表現任務（GRASPS）與評量規準（Rubrics），再規劃引起動機與發展教學活動。
- 評量尺規：提供分析性評量尺規表格（4個等級）。
- 格式：成品一律以 Markdown 及 Word 格式輸出至 `output/`。

## 怎麼用
1. 將您的教案需求或科目主題寫入 `input/requirements.txt`。
2. 執行 `/plan` 啟動設計。
3. 至 `output/` 獲取最終教案架構。
