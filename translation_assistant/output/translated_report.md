# 雙語對照翻譯對照表

| 原文 | 指定語言譯文 |
| :--- | :--- |
| Artificial Intelligence (AI) is transforming the world. | 人工智慧 (AI) 正在改變世界。 |
| Large Language Models (LLMs) allow humans to interact with machines using natural language. | 大型語言模型 (LLMs) 讓人類能夠使用自然語言與機器互動。 |
| This technology is incredibly powerful but must be used responsibly. | 這項技術非常強大，但必須負責任地使用。 |

### 註釋與說明

註釋：
1. LLM (Large Language Model) 翻譯為大型語言模型。
2. AI (Artificial Intelligence) 翻譯為人工智慧。
