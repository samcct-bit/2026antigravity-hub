第一章

叩首的意義與心法

「叩首禮敬諸佛可以攝外放的妄心，達到定靜功夫。」

叩首的四大核心心法

1. 收攝妄心
藉由手抱合同、意守玄關，一叩一叩慢慢叩，收束攀緣心念，達到定靜與清靜。
2. 感恩懺悔
五體投地至誠叩首，感念天恩師德，真心懺悔身口意過錯，消解業障冤孽。
3. 迴光返照
找到自性正門，藉三寶點開生死竅門。念念不離自性，在行住坐臥中念念相續。
4. 培植內德
叩首中心神安寧，覺性提高，從根本改毛病去脾氣、修個性、造就平順命運。

第二章

叩首的正確姿勢與要領

「腰帶動頭與手一起動，力量由腳來支撐，叩首非叩手。」

正確叩首動作要領

1. 腰部彈簧帶動
臀部抬高，背成弧形下彎。以腰部控制頭手起落，手絕不出力，雙腿要併攏。
2. 慣性甩頭震動
合同落拜墊瞬間，頭部完全放鬆隨慣性輕微甩頭，藉離心力使玄關自然震動。
3. 合同蓋印起落
合同起落約0.5公分，像蓋印章般發出聲音。兩手小指無名指隨合同起落敲擊。
4. 意守凝視頂上
眼八分閉二分張，凝視合同中心。舌頂上顎產生津液，心裡輕輕意守玄關竅。

氣機與呼吸的配合

☯ 三寶齊用與調息

呼吸需緩慢至聽不見聲音。配合腹式深呼吸，吸氣時想像空氣從玄關吸入（默念真經首字），吐氣時想像體內濁氣從玄關吐出（默念後四字）。

☯ 腳尖與小腿出力

腳膝蓋置於拜墊三分之一處，腳尖緊貼地面輕輕出力支撐，臀部微抬重心前傾。身體關節放鬆，感受腰部像彈簧般自動叩首的「氣機」現象。

叩首呼吸配合法 (玄關式呼吸)

吸氣 (約10秒) 意守玄關 + 默念真經首字
吐氣 (約20秒) 慢慢吐出濁氣 + 默念真經後四字
慢慢叩 不急不躁，以腰能承受的速度叩首

常見錯誤 VS 正確姿勢

✕ 常見不標準姿勢
  • 頭部提得太高，或頭太低貼近合同
  • 叩頭太用力，頭與背平直未下彎
  • 腰未帶動，只用雙手用力叩擊拜墊
  • 雙腿未併攏，手部緊繃用力未放鬆
  • 眼睛緊閉，或者報數叩首速度過快
VS
✓ 正確標準動作
  • 額頭離合同大約 1.5 到 2 個拳頭
  • 背部往下彎曲成弓箭狀，頭部放鬆
  • 腰像彈簧般自動帶動頭與手起落
  • 雙腿併攏，腳尖平貼地面出力支撐
  • 眼八分閉二分張，專注凝視合同

自我評量：16種姿勢檢測

頭、眼、口檢測

  • 頭提太高 / 頭太低或貼近合同
  • 叩頭太用力 / 頭背平直未往下彎
  • 腰部未帶動，只叩手、不叩頭
  • 叩首時沒有舌頂上顎
  • 眼睛閉著或沒有凝視合同中心
  • 報數與叩首速度太快太急 / 多叩

手、合同、腿檢測

  • 手部有出力，肌肉僵硬未放鬆
  • 手肘太開或僵直未微彎曲
  • 手沒有抱合同，而各自分開叩
  • 合同貼著拜墊不動或只動一點
  • 合同抱拳、拱起或提得太高
  • 雙腿未併攏，重心偏移
💡 提示：若覺得身體某部位叩起來會酸痛不舒服，多半是姿勢不夠放鬆標準，請隨時對照調整。
