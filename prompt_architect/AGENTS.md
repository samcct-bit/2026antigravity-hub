# 對話指令架構設計工作區 (prompt_architect)

一條「給對話需求 ➔ 疊加與版本控制 ➔ 輸出 YAML 行為指令」的可重複工作流。

## 固定偏好
- 格式：嚴格使用 YAML 語法輸出。
- 核心約束：修改必須完全繼承上一版的 YAML 內容，並使版本號（如 `v1.0` -> `v1.1`）遞增。
- 成品一律輸出至 `output/`。

## 怎麼用
1. 將您的對話機器人需求寫入 `input/requirements.txt`。若需要更新現有指令，將舊版指令放在該檔中並附上修改要求。
2. 執行 `/engineer` 啟動設計。
3. 至 `output/` 獲取最新的 YAML 指令檔。
