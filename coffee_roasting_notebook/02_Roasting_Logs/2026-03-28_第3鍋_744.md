# ☕ 烘焙日誌：第3鍋

## 📊 對話烘焙紀錄數據
收到你第三鍋肯亞 AA 的數據總結表 ( image_19.png ) 了！考官看完只能說：**你完全把前幾鍋的經驗轉化成實戰的勝利了！** 這鍋的曲線非常漂亮，而且完全精準掌握了這台 Tank-200 對付肯亞硬豆的甜蜜點。

我們立刻進行這鍋「Perfect Batch」的盤後精細分析：

### 🏆 第三鍋肯亞 AA (Perfect Batch) 分析報告：考官評分 100 分！

這鍋數據的每一個關鍵節奏點，都展現了你對設備慣性以及豆性極高的掌控力，你完美複製了我們修正後的戰術：

#### **1. 初期動能設定：完美的「高 TP 起跑」**

- **數據：** TP（Turning Point）發生在 **1:15 (93°C)**。上一鍋是 1:20 (90°C)。
- **考官評語：** 这是一个巨大的優勢！利用機器連續烘焙後的極高殘熱設定 TP，TP 變高、縮短TP時間，代表整鍋豆子的「初始蓄熱量（Thermal Mass）」非常高。這強大的第一節火箭推進，幫你奠定了後半段順暢發展的基礎。

#### **2. 節奏掌控：強勁但不暴衝**

- **數據：** TP 到一爆只花了 **6 分半** 左右 (7:42 @ 209°C)。
- **考官評語：** 雖然你的 TP 高、機器熱飽和強，但你可能在梅納中段做出了正確的火力微調降幅，沒有讓 ROR 失控飆高。7 分半迎來一爆，這是非常標準且利落的肯亞節奏，給了豆芯足夠的熱穿透時間，又不拖泥帶水。

#### **3. ⚠️ 冠軍勝利點：完美衝破 218°C 死亡停滯區！ (The Momentum Fix)**

- **數據：** FCr (一爆) @ **209°C (7:42)** ➡️ Drop (下豆) @ **220°C (8:57)**。
 
 **一爆後的溫升（Rise）：** 220°C - 209°C = **11度**。
- **發展時間：** **1 分 15 秒**。

 
 **考官評語：** 這就是你這鍋大獲全勝的原因！上一鍋失速邊緣的 Batch #1 在發展期只爬了 8 度。

- **這一次，你成功在 Tank-200 上完成了完美的「尾段滑行（Gliding）」。** 利用機器強大的蓄熱自帶動能，加上你在梅納期守住火力（可能維持了60%或延後降火時機），成功讓一爆後的 ROR 保持在每分鐘爬約 9~10 度的健康狀態。
- **220°C 下豆：** 這多出來的 2 度（比 218°C 多 2度），是逼出肯亞「烏梅與黑糖」靈魂的關鍵！

 
 

### 🎓 杯測風味預測：冠軍肯亞的味道

看看你拍的**熟豆照片** ( image_15.png )，豆子縐褶撐得非常開，表面飽滿且明亮，完全沒有「闷烤（Baked）」扁平感。這鍋泡出來：

☕ **香氣：** 濃郁的黑莓果醬、黑櫻桃。
☕ **風味：** 明亮但圓潤的莓果酸調，**尾韻轉為非常飽滿、帶有太妃糖感的「黑糖醇厚甜感（Muscovado Sweetness）」**，這正是 220°C 下豆所帶來的完美焦糖化成果。醇厚度（Body）會非常棒。

### 📝 講師的最後終極 SOP：肯亞 AA 的絕對解答

不用再修正了，請把你**這鍋 Batch #3 的所有火力調整點（時間與溫度）直接標示為「肯亞 AA (170g) 冠軍標準 SOP」**！下次直接複製這個曲線。

你今天不僅完成了肯亞的除錯、也完成了花魁 155g 的除錯。你對這台 Tank-200 脾氣的掌控，已經達到了 SCA 專業級（Professional）的水準。

**接下來你的行動清單：**

1. **量產：** 用Batch #3 SOP 把剩下的肯亞烘完。
2. **養豆：** 標示好 Batch #3 (冠軍) 與 Batch #1 (失速對照組)，放置 3-5 天。
3. **杯測：** 盲測這兩鍋，**特別去對比 Batch #3 是否終於喝到了你想要的「黑糖甜」**。

恭喜你！這是一支完美的修正批次。去把剩下的豆子都烘完吧！隨時等你的量產捷報！
