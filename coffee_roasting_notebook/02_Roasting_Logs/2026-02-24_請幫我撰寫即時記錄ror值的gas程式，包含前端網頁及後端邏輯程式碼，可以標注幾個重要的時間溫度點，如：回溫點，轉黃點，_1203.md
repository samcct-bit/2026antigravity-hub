# ☕ 烘焙日誌：請幫我撰寫即時記錄ror值的gas程式，包含前端網頁及後端邏輯程式碼，可以標注幾個重要的時間溫度點，

## 📊 對話烘焙紀錄數據
你好！身為 **SCA 專業全方位認證講師 (AST)**，很高興能協助你將烘焙理論與數位化工具結合。

在 SCA 烘焙模組（Roasting Module）中，**RoR (Rate of Rise，升溫率)** 是衡量熱能傳遞效率與預測風味走向的核心指標。掌握了 RoR，你就能更精準地避免「失速 (Stall)」或「燥熱 (Flick)」等技術缺陷。

以下我為你準備了這份**烘焙數據即時記錄工具**的開發架構。這套工具基於 **Google Apps Script (GAS)**，將 Google Sheets 變成你的烘焙曲線工作站。

---

## 📑 培訓教材：RoR 曲線管理與數據邏輯

在進入代碼之前，我們先確立這套系統的「核心邏輯」，這也是學員在進行自主訓練時必須理解的：

| 階段關鍵點 | 定義與重要性 |
| --- | --- |
| 回溫點 (TP) | 豆溫與爐溫達到平衡的最低點，標誌著吸熱反應的正式開始。 |
| 轉黃點 (Yellowing) | 美拉德反應啟動，水分開始大量蒸發，香氣前驅物開始形成。 |
| 一爆 (FC Start) | 水蒸氣壓力衝破豆體，放熱反應劇烈，是決定焙度的分水嶺。 |
| 發展期 (DTR%) | 從一爆開始到出豆的時間佔總時長的比例，通常建議在 15%-25%。 |
| 失重率 (Weight Loss) | 物理變化指標，反映脫水與有機物損耗。 |

## 🛠 Google Apps Script 完整代碼

請依照以下步驟操作：

1. 開啟一個 Google 表格。
2. 點擊「延伸功能」>「Apps Script」。
3. 建立兩個檔案： Code.gs  (後端) 與  index.html  (前端)。

### 1. 後端邏輯 ( Code.gs )

 function doGet() {
  return HtmlService.createHtmlOutputFromFile('index')

// 儲存烘焙紀錄至試算表
function recordData(data) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("烘焙紀錄") || ss.insertSheet("烘焙紀錄");
  
  // 如果是新表格，寫入標題
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["時間", "豆溫", "RoR", "事件備註", "總時長", "發展比例", "預估Agtron", "失重率"]);
  }
  
  sheet.appendRow([
    data.time, 
    data.temp, 
    data.ror, 
    data.event, 
    data.totalTime, 
    data.dtr, 
    data.agtron, 
    data.weightLoss
  ]);
}

  <script>
    let startTime, timerInterval;
    let prevTemp = 0, prevTime = 0;
    let fcStartTime = 0;
    let events = [];

    // 每 30 秒自動計算一次 RoR (可調整)
    setInterval(updateRoR, 30000);

    function startTimer() {
      startTime = Date.now();
      timerInterval = setInterval(() => {
        let diff = Date.now() - startTime;
        let m = Math.floor(diff / 60000);
        let s = Math.floor((diff % 60000) / 1000);
        document.getElementById('timerDisplay').innerText = 
          (m < 10 ? "0" : "") + m + ":" + (s < 10 ? "0" : "") + s;
      }, 1000);
    }

    function updateRoR() {
      let currentTemp = parseFloat(document.getElementById('tempInput').value);
      let currentTime = (Date.now() - startTime) / 60000; // 分鐘
      
      if (prevTemp > 0) {
        let ror = (currentTemp - prevTemp) / (currentTime - prevTime);
        document.getElementById('rorDisplay').innerText = ror.toFixed(1);
        saveToSheet(currentTemp, ror.toFixed(1), "");
      }
      
      prevTemp = currentTemp;
      prevTime = currentTime;
    }

    function markEvent(eventName) {
      if (eventName === '入豆') startTimer();
      if (eventName === '一爆 (FC)') fcStartTime = (Date.now() - startTime) / 1000;
      
      let currentTemp = document.getElementById('tempInput').value;
      events.push({name: eventName, time: document.getElementById('timerDisplay').innerText, temp: currentTemp});
      saveToSheet(currentTemp, document.getElementById('rorDisplay').innerText, eventName);
      alert("已記錄: " + eventName);
    }

    function finishRoast() {
      clearInterval(timerInterval);
      let endTime = (Date.now() - startTime) / 1000;
      let devTime = endTime - fcStartTime;
      let dtr = (devTime / endTime * 100).toFixed(2);
      
      // 失重率計算
      let gw = document.getElementById('greenWeight').value;
      let rw = document.getElementById('roastedWeight').value;
      let wl = ((gw - rw) / gw * 100).toFixed(2);

      // 預估 Agtron (簡易線性模型: 基於出豆溫度, 僅供參考)
      // 公式假設: 210度約 Agtron 55, 每升1度減少約 3 點
      let lastTemp = document.getElementById('tempInput').value;
      let estAgtron = Math.round(110 - (lastTemp - 190) * 2.5);

      document.getElementById('summary').style.display = 'block';
      document.getElementById('summaryList').innerHTML = `
        <li>發展期長度: ${Math.floor(devTime/60)}分${Math.floor(devTime%60)}秒</li>
        <li>發展佔比 (DTR): ${dtr}%</li>
        <li>失重率: ${wl}%</li>
        <li>預估 Agtron 值: ${estAgtron} (±5)</li>
      `;
    }

    function saveToSheet(t, r, e) {
      google.script.run.recordData({
        time: document.getElementById('timerDisplay').innerText,
        temp: t,
        ror: r,
        event: e
      });
    }
  </script>

## 📽 自主訓練翻頁式簡報 (教學架構)

 您可以將以下內容直接放入投影片或筆記中：

### 第一頁：烘焙目標設定

- **學員任務**：設定預期出豆溫度與總烘焙時間。
- **理論重點**：了解不同產區豆性（密度、含水率）對熱吸收的影響。
- **操作**：在 GAS 介面輸入生豆重量。

### 第二頁：RoR 的三段管理

- **脫水期**：RoR 應保持高位但平穩。
- **梅納反應期**：RoR 開始緩降，觀察轉黃點。
- **一爆與發展**：嚴防 RoR 劇烈噴發（Flick），確保 DTR 佔比符合目標風味。

### 第三頁：數據解讀與反饋

- **失重率分析**：$12-15%$ 為精品淺焙常態；$>18%$ 可能過度脫水。
- **Agtron 值預估**：透過出豆溫與 DTR 綜合判斷顏色深度，建立感官與數據的連結。

---

### 💡 專業講師的最後叮嚀

這套程式提供了一個數位基礎，但在 SCA 考場上，我們更看重的是**「修正能力」**。

1. **RoR 延遲**：請記住，豆溫探針讀取有物理延遲，程式反映的是 30 秒前的趨勢，操作火力時需提前預判。
2. **Agtron 修正**：程式中的預估值是基於通用曲線。建議你實際使用色卡對校後，微調代碼中的  estAgtron  係數。
