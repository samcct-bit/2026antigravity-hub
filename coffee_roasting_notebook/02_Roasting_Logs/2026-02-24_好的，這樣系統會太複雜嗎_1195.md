## 🔧 簡化策略：為什麼「模板」反而能讓操作變簡單？

對於藝伎或莫札特這種高難度的豆子，我們將複雜的邏輯藏在背景。你只需要在烘焙前選好「豆種」，系統就會自動幫你做兩件事：

1. **動態調整目標曲線 (Target Overlay)**：讓你知道這鍋藝伎現在是太快還是太慢。
2. **自動調整警告門檻**：例如烘莫札特時，一爆後的 RoR 只要超過 $5$ 就發警報，而不是一般豆子的 $8$。

### 整合後的「預設選單」邏輯代碼

你只需要在  index.html  的 HTML 部分加入一個簡單的下拉選單：

 <select id="roastMode" class="form-select d-inline-block w-25" onchange="applyMode()">
  <option value="standard">一般標準 (Standard)</option>
  <option value="highSugar">高糖分/處理法 (Mozart/Honey)</option>
  <option value="floral">極致花香 (Gesha/Light)</option>
</select>
  
 然後在 JavaScript 中定義邏輯：

 function applyMode() {
  const mode = document.getElementById('roastMode').value;
  if (mode === 'floral') {
    // 自動將圖表目標曲線切換為「低溫長發展」模式
    alert("已載入花香模式：系統將加強一爆後的 RoR 監控。");
    // 此處可寫入切換 targetData 的邏輯
  }
}

## ☕ 導師級實戰建議：解決你「DTR 15% 卻沒花香」的痛點

 針對你提到的：**「莫札特一爆後超過 1 分鐘就沒花香」**，這通常不是時間的問題，而是**「熱動能 (Thermal Momentum)」**過剩。

### 為什麼 1 分鐘會太久？

在 Tank 200 這種小型機台，如果一爆時火力沒退夠，這一分鐘內豆溫可能會上升 $10-12^\circ C$。對藝伎或莫札特來說，一旦溫度衝過 $200^\circ C$，那些優雅的「乙酸乙酯（果香來源）」就會被焦糖化反應後的「苦甜味」覆蓋掉。

### 你的修正方案：「軟著陸 (Soft Landing)」

如果你希望 DTR 有 15%（假設總時長 8 分鐘，發展需約 72 秒），但又要保住花香，你必須讓這一分鐘內的**溫升控制在 $4-5^\circ C$ 以內**。

- **操作指引**：
 
 **提前收火**：在預測一爆前 30 秒，將瓦斯調到極小（甚至是關火靠餘溫）。
- **拉大風門**：利用風門帶走一爆瞬間產生的劇烈熱能。
- **GAS 輔助**：監控畫面上的 RoR，進入一爆後，RoR 應立即壓在 $3-5$ 之間。

這樣一來，即使你發展了 75 秒，出豆溫依然很低，花香就會被「鎖」在豆子裡。
