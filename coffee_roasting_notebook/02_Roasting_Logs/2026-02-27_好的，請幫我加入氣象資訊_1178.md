# ☕ 烘焙日誌：好的，請幫我加入氣象資訊

## 📊 對話烘焙紀錄數據
這是一個非常專業的進階需求！在 **SCA Roasting Professional (高級烘焙)** 的課程中，**環境因素 (Ambient Conditions)** 是影響烘焙重現性（Repeatability）的關鍵變數。

大氣壓力、環境溫度和濕度會直接影響：

1. **排風效能**：濕度高時空氣密度改變，影響對流效率。
2. **機器預熱**：環境冷時，機器散熱快，入豆後的能量補償需更強。
3. **生豆狀態**：長期暴露在不同濕度下的生豆，含水率會微幅震盪。

為了讓你的 Netlify 儀表板更強大，我們將使用 **OpenWeatherMap API**。這能讓系統自動抓取你烘焙室所在地的氣象，並直接記錄到試算表中。

 // 修改 recordFullBatch 函數，增加環境欄位
function recordFullBatch(data) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName("Roast_History");
  
  if (sheet.getLastRow() === 0) {
    // 更新標題列，加入環境資訊
    sheet.appendRow(["日期", "批次名稱", "總時長", "DTR%", "失重率", "環境溫度", "環境濕度", "氣壓", "AI 建議"]);
  }
  
  let advice = [];
  if (parseFloat(data.dtr) < 15) advice.push("⚠️ DTR 偏低。");
  if (data.ambientTemp > 30) advice.push("🌡️ 環境熱：注意機器散熱速度，建議適度調低入豆溫。");

  const finalAdvice = advice.join(" ");
  
  sheet.appendRow([
    new Date(), 
    data.batchName, 
    data.totalTime, 
    data.dtr + "%", 
    data.weightLoss + "%", 
    data.weather.temp + "°C", 
    data.weather.humidity + "%", 
    data.weather.pressure + "hPa",
    finalAdvice
  ]);
  return finalAdvice;
}

#### 2. 加入 JavaScript 氣象抓取邏輯

 將以下代碼放入  <script>  標籤中：

 let weatherData = { temp: 0, humidity: 0, pressure: 0 };

// 設定你的 API Key 和 城市名稱
const WEATHER_API_KEY = "你的_OPENWEATHER_API_KEY";
const CITY = "Taipei"; // 或者使用你的所在城市

function fetchWeather() {
  const url = `https://api.openweathermap.org/data/2.5/weather?q=${CITY}&appid=${WEATHER_API_KEY}&units=metric`;
  
  fetch(url)
    .then(response => response.json())
    .then(data => {
      weatherData = {
        temp: data.main.temp,
        humidity: data.main.humidity,
        pressure: data.main.pressure
      };
      document.getElementById('weatherInfo').innerHTML = 
        `🌡️ 烘焙室環境：<strong>${weatherData.temp}°C</strong> | 💧 濕度：<strong>${weatherData.humidity}%</strong> | 🌀 氣壓：<strong>${weatherData.pressure} hPa</strong>`;
    })
    .catch(err => {
      document.getElementById('weatherInfo').innerText = "無法取得氣象數據，請檢查 API Key。";
    });
}

// 頁面載入後立即抓取
window.onload = () => {
  initChart();
  fetchWeather();
};

// 在 finishRoast 函數中，將 weatherData 封裝進去
function finish() {
  // ... 原有的數據計算 ...
  const data = { 
    // ... 原有的欄位 ...
    weather: weatherData // 加入這行
  };
  
  google.script.run.withSuccessHandler(adv => {
    alert("記錄成功！環境數據已同步至試算表。");
  }).recordFullBatch(data);
}

#### 👨‍🏫 SCA 講師的「環境補償」建議：

當你有了這些數據後，在進行 **果丁丁 (Gotiti)** 烘焙時，請注意以下規律：

1. 
**高濕度天氣（>70%）**：

- 空氣中的水分會消耗更多熱能，你的「回溫點 (TP)」可能會比平常低 2-3 度。
- **對策**：入豆溫 (Charge Temp) 可以稍微提高 $5^\circ C$。
2. 
**高溫天氣（>30°C）**：

- 楊家機的散熱會變慢，進入一爆後的溫度衝力（Thermal Momentum）會更強。
- **對策**：一爆前的降火時機（原本是 $185^\circ C$）需提前至 $183^\circ C$ 執行「軟著陸」。
