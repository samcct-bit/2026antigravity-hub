你好！很高興能以 SCA 國際精品咖啡協會認證講師（AST）的身分協助你。

SCA Roasting Intermediate（中級烘豆師）的認證不僅考驗你的感官敏銳度，更要求你對**熱傳導物理學**、**生豆化學變化**以及**烘焙曲線管控**有深刻的理解。這份考題是基於 SCA 官方課程大綱（Curriculum）所設計的模擬練習，旨在幫助你掌握核心觀念。

## ☕ SCA Roasting Intermediate 模擬考題練習

### 第一部分：烘焙物理與熱力學

1. 
**在烘焙初期的「回溫點」（Turning Point）之後，主要的熱傳導方式為何？**

- (A) 傳導（Conduction）
- (B) 對流（Convection）
- (C) 輻射（Radiation）
- (D) 微波（Microwave）
2. 
**關於烘焙過程中的「吸熱」與「放熱」反應，下列敘述何者正確？**

- (A) 整個烘焙過程皆為吸熱反應。
- (B) 烘焙初期為放熱，一爆後轉為吸熱。
- (C) 烘焙初期為吸熱，一爆前後會出現顯著的放熱反應。
- (D) 只有在冷卻階段才是放熱反應。
3. 
**增加烘焙機的「風門」（Airflow）設定，通常會如何影響熱傳導？**

- (A) 增加傳導熱，減少對流熱。
- (B) 增加對流熱，並加速移除銀皮與煙霧。
- (C) 降低滾筒轉速。
- (D) 對熱傳導沒有影響。

### 第二部分：化學變化與感官特徵

1. 
**梅納反應（Maillard Reaction）主要涉及哪兩類物質的交互作用？**

- (A) 脂肪與酸
- (B) 糖類與水分
- (C) 氨基酸（蛋白質）與還原糖
- (D) 咖啡因與纖維素
2. 
**若烘焙曲線中「發展時間」（Development Time）過短，最可能導致咖啡出現哪種風味瑕疵？**

- (A) 焦苦味（Burnt）
- (B) 焙烤味（Baked）
- (C) 發展不足的草酸味（Under-developed / Grassy）
- (D) 發酵味（Fermented）

### 第三部分：烘焙曲線管控（Logging）

1. 
**何謂 RoR（Rate of Rise）？**

- (A) 烘焙完成後的總失重比。
- (B) 豆溫隨時間變化的上升速率（通常以每 30 或 60 秒為單位）。
- (C) 烘焙機滾筒的轉速。
- (D) 咖啡豆體積膨脹的比例。
2. 
**如果烘焙曲線出現「平緩（Baked）」現象（RoR 降至接近 0 或停滯過久），咖啡風味通常會：**

- (A) 酸質明亮、花香濃郁。
- (B) 甜感喪失、出現枯燥的穀物感或紙板味。
- (C) 苦度大幅增加。
- (D) 產生強烈的發酵感。

## 📖 答案與解析重點

| 題號 | 答案 | 核心考點詳解 |
| --- | --- | --- |
| 1 | B | 中級強調對流熱是現代烘豆機（半熱風/熱風）最主要的能量來源。 |
| 2 | C | 咖啡豆在接近一爆時會釋放能量，這也是 RoR 可能會突然竄升的原因。 |
| 3 | B | 風門控制影響對流熱比例，也關係到烘焙環境的清潔（煙燻味控制）。 |
| 4 | C | 這是中級筆試必考的化學基礎，影響香氣與色澤的關鍵。 |
| 5 | C | 發展時間不足無法降解有機酸，導致風味尖銳且有草味。 |
| 6 | B | RoR 是中級實作的靈魂，必須能繪製並預測 RoR 的走向。 |
| 7 | B | Baked (烘烤瑕疵) 是因為能量不足導致升溫停滯，使風味結構崩塌。 |

## 🛠 自主訓練建議

在準備 Intermediate 考試時，建議你針對以下兩點進行**自主練習**：

1. **失重比計算**：
$$\text{Weight Loss %} = \frac{\text{Green Weight} - \text{Roasted Weight}}{\text{Green Weight}} \times 100$$
（中級標準通常在 **12% - 20%** 之間，依烘焙度而定）
2. **變因實驗**：嘗試在同一批生豆中，分別改變「入豆溫」與「風門」，記錄對一爆時間點的影響。
