# ☕ 烘焙日誌：彙整一份「中級杯測常見風味術語表（中英對照）

## 📊 對話烘焙紀錄數據
這份「中級杯測常見風味術語表」是專為 SCA Roasting Intermediate 考生準備的。在中級認證中，考官非常看重你是否能使用**標準化語言**來描述產地風味（Origin Character）與烘焙造成的影響（Roast Character）。

在進行三角杯測或口試時，準確地說出這些詞彙，能展現你作為專業烘豆師的素養。

---

## ☕ SCA 烘焙中級杯測術語表 (中英對照)

### 1. 核心評測維度 (Core Attributes)

這是杯測表上的基本項目，描述這些項目的「質感」比描述「強度」更重要。

| 中文術語 | 英文術語 | 說明與應用情境 |
| --- | --- | --- |
| 香氣 | Aroma / Fragrance | 乾粉香 (Fragrance) 與濕香氣 (Aroma)。 |
| 酸質 | Acidity | 區分酸的類型（如：亮麗的、尖銳的、平板的）。 |
| 醇厚度 / 口感 | Body / Mouthfeel | 咖啡液在舌頭上的重量感與觸感。 |
| 餘韻 | Aftertaste / Finish | 吞嚥後留在口腔的氣味與感覺。 |
| 平衡度 | Balance | 酸、苦、甜之間的協調程度。 |
| 甜感 | Sweetness | 焦糖化反應帶來的正向能量。 |
| 潔淨度 | Clean Cup | 風味是否透明、無雜質（瑕疵豆會破壞潔淨度）。 |

---

### 2. 烘焙瑕疵相關術語 (Roast Defect Terms) - **考試核心**

當你發現那杯「不同的咖啡」時，通常會用到這些詞：

| 中文術語 | 英文術語 | 缺陷類型與感官特徵 |
| --- | --- | --- |
| 發展不足 | Under-developed | 帶有 生澀感 (Grassy)、穀物味 (Cereal)、生花生 (Raw peanut)。 |
| 悶烘 | Baked | 風味 平板 (Dull)、紙箱味 (Cardboard)、空洞的 (Empty)、缺乏香氣。 |
| 焦灼 | Scorched | 帶有 尖銳的焦苦 (Sharp bitter)、煙燻味 (Smoky)。 |
| 端點灼傷 | Tipped | 咖啡豆兩端焦黑，導致 灰燼感 (Ashy)、碳味 (Carbon)。 |
| 發展過度 | Over-roasted | 苦味主導，缺乏 產地特徵 (Origin Character)。 |

---

### 3. 酸質描述詞 (Acidity Descriptors)

判斷發展程度（Development）的重要依據：

| 中文術語 | 英文術語 | 感官聯想 |
| --- | --- | --- |
| 亮麗的 / 明亮的 | Bright / Vibrant | 正向的高海拔優質酸質。 |
| 圓潤的 | Round / Mellow | 經過良好發展，酸質不刺口。 |
| 尖銳的 / 粗糙的 | Sharp / Harsh | 常出現在發展不足或烘焙過快的豆子。 |
| 平板的 / 呆滯的 | Flat / Dull | 常出現在悶烘 (Baked) 或烘焙時間過長的豆子。 |
| 醋酸般的 | Vinegary / Acetic | 過度發酵或極端發展不足。 |

---

### 4. 口感與觸感 (Body & Mouthfeel)

判斷烘焙計畫是否達成目標（如：增加醇厚度）：

| 中文術語 | 英文術語 | 感官聯想 |
| --- | --- | --- |
| 絲滑的 / 圓潤的 | Silky / Smooth | 良好的油脂感與甜感。 |
| 厚實的 / 重質的 | Heavy / Syrupy | 深度烘焙或長時間梅納反應帶來的質感。 |
| 單薄的 / 水感 | Thin / Watery | 發展不足或悶烘導致的口感缺失。 |
| 乾澀的 | Astringent / Drying | 餘韻帶有不舒服的抓舌感（常見於 Flick 或發展不足）。 |
| 粗糙的 | Rough / Gritty | 顆粒感明顯，不細緻。 |

---

### 5. 正向烘焙風味 (Positive Roast Characters)

描述良好的梅納反應與焦糖化結果：

| 中文術語 | 英文術語 | 描述 |
| --- | --- | --- |
| 堅果感 | Nutty | 烘烤核桃、榛果、杏仁。 |
| 焦糖感 | Caramelly | 糖類受熱後的正向甜香。 |
| 巧克力感 | Chocolaty | 黑巧克力、牛奶巧克力或可可。 |
| 烤麵包香 | Toasty | 脫水階段完成時的特徵香氣。 |
| 複雜度 | Complexity | 具備豐富的層次感（酸、甜、香氣）。 |

---

## 💡 考試時的術語應用範例 (三角杯測描述)

當考官問你：「為什麼這杯不同？」你可以這樣回答：

- 
**如果發現發展不足：**

> 
「這杯的潔淨度較低，酸質顯得 **尖銳 (Sharp)** 且帶有明顯的 **穀物味 (Grainy/Cereal)**，餘韻有 **乾澀感 (Astringent)**。我判斷這是 **發展不足 (Under-developed)** 的瑕疵，可能是 DTR% 過低所致。」

- 
**如果發現悶烘：**

> 
「這杯咖啡的香氣非常 **平板 (Dull/Flat)**，口感顯得 **空洞 (Empty)**，並帶有輕微的 **紙箱味 (Cardboard)**，缺乏甜感。這符合 **悶烘 (Baked)** 的特徵，通常源於 RoR 停滯。」

---
