## 🛠️ 整合版 GAS 代碼優化

這套代碼將允許你在前端切換不同的**烘焙檔案 (Profiles)**。

### 1. 後端邏輯 ( Code.gs )

更新後的後端能根據選擇的機型與豆種，抓取對應的黃金曲線。

 // 根據機型與豆種名稱抓取黃金曲線
function getDynamicTarget(machine, bean) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName("GoldenBatch_Master"); 
  const data = sheet.getDataRange().getValues();
  
  // 邏輯：在 Master 表中尋找符合該機型與豆種的時間/溫度點
  return data.filter(r => r[0] === machine && r[1] === bean)
             .map(r => [r[2], r[3], r[4]]); // 傳回 [時間, 溫度, 火力指引]
}

function recordFullBatch(data) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName("Roast_History") || ss.insertSheet("Roast_History");
   
  
   
  sheet.appendRow([
    now, 
    data.machine, 
    data.beanType, 
    data.batchName, 
    data.totalTime, 
    data.dtr + "%", 
    data.weatherInfo, // 包含溫度/濕度
     
  ]);
  return "數據已整合儲存";
}

## 📊 整合環境因素的 SCA 專業判斷邏輯

 ：

### 1. 天氣狀態補償

- **高濕度 (Humidity > 70%)**：水蒸氣壓會影響排風效率。系統應提醒：*「環境濕度較高，建議轉黃後微增風門以維持乾淨度。」*
- **低溫環境**：機殼散熱快。系統應提示：*「入豆溫建議補償 +5°C，以防回溫點過低導致脫水不完全。」*

### 2. 品種豆性差異

- 。
 
 **邏輯**：當系統偵測到豆種為「日曬」，會自動在一爆前 1 分鐘加強警告：*「進入日曬豆軟著陸區，請務必收火。」*

 
 。 
 

### 3. 不同烘豆機的熱傳導率

- **楊家半熱風**：蓄熱穩定但反應有延遲。
- **全對流小機台**：反應極快。
 
 **整合方式**：根據選擇的機型，系統自動調整 **RoR 平滑化視窗** 的長度。小機台使用 15 秒視窗，楊家機使用 30 秒視窗。
