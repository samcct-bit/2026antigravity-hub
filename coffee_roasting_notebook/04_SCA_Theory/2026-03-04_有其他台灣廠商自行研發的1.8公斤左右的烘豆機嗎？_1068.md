# 📚 SCA 考官理論：有其他台灣廠商自行研發的1.8公斤左右的烘豆機嗎？

## 📋 對話理論筆記
除了我們先前討論過的「三大天王」（盧貝思、楊家、貝拉）之外，台灣作為全球咖啡器材研發的重鎮，確實還有幾家深藏不露、極具工藝水準的本土品牌，在 1.5kg 到 2kg 級距中擁有極高的評價。

身為 SCA 講師，我特別為你整理出這些「巷子內」的台灣研發品牌，它們各有獨特的物理設計邏輯：

### 1. 蕭氏烘豆機 (Hsiao Roaster)

- **型號規格**：**HS-1.5 / HS-2.0**
- **品牌特色**：由台灣資深玩家與工程師蕭先生研發，以「極致的溫控穩定性」聞名。其熱交換系統設計非常優異，能提供極為乾淨的熱風性能。
- **講師點評**：這台機器的風火平衡感極佳，非常適合用來表現精品咖啡的「高海拔酸質」與「花果香氣」。

### 2. A-Roaster (力揚機械)

- **型號規格**：**A-Roaster 1.5kg / 2.0kg**
- **品牌特色**：來自台中的品牌，強項在於其精密加工的滾筒與葉片設計，翻攪效果極其均勻。
- **講師點評**：其排煙與風門的細膩度在同級距中表現亮眼，對於想要精準控制「美納反應」階段的烘豆師來說，是非常好上手的武器。

### 3. JIA WEI (嘉味 / 或是通稱的「大甲王」)

- **型號規格**：**JW-1.5 / 2.0**
- **品牌特色**：雖然低調，但在中南部烘豆圈有極強的口碑。其機器構造厚實，導熱系數經過特別計算。
- **講師點評**：屬於「實戰型」機器，蓄熱與火力銜接非常紮實，烘焙出的豆子體現出極佳的「甜感」與「醇厚度 (Body)」。

### 4. 凱勝 (Kaisheng / K-Series)

- **型號規格**：**K-1.5 / K-2.0**
- **品牌特色**：這幾年逐漸嶄露頭角的台灣自研品牌，強調全機不鏽鋼與耐火材料的應用，外觀與質感偏向現代簡約。
- **講師點評**：對於講究工作環境美學、同時需要精確數位顯示的精品咖啡店來說，這是一個具備高性價比的選擇。
