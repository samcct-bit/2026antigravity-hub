# 📚 SCA 考官理論：我先試試看上一步驟的網頁，但您"在資料夾內建立一個名為 index.html 的檔案，並貼入以下代碼："並沒有給我ind

## 📋 對話理論筆記
真是不好意思！身為講師，這就像是我把烘焙機的參數都調好了，卻忘了給你工作室的鑰匙。

要讓 Netlify 成功運作，那個在資料夾裡的  index.html  扮演的是「橋樑」的角色。它不包含烘焙邏輯（邏輯都在 Google 雲端），它的任務是把長長的 Google 網址「包裝」成你專屬的 Netlify 網址。

以下是你要放在資料夾內、準備上傳給 Netlify 的  index.html  完整代碼：

---

### 📄 Netlify 專用：index.html (外殼包裝)

請新建一個記事本，貼入以下內容，並存檔為  index.html ：

 <!DOCTYPE html>
<html lang="zh-TW">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
    <title>SCA Pro Master | 專業烘焙控制台</title>
    <style>
        body, html { 
            margin: 0; 
            padding: 0; 
            height: 100%; 
            width: 100%;
            overflow: hidden; 
            background-color: #121212; /* 配合我們控制台的深色主題 */
        }
        iframe { 
            position: absolute;
            top: 0;
            left: 0;
            width: 100%; 
            height: 100%; 
            border: none; 
        }
    </style>
</head>
<body>
    <iframe src="你的_GOOGLE_APPS_SCRIPT_部署網址_末尾是_exec"></iframe>
</body>
</html>
  

---

### 💡 講師的特別提醒（必看）

 在執行這一步前，請確保你已經完成以下動作，否則 Netlify 會顯示空白或錯誤：

1. 
**Google 端權限設定**：
在 Google Apps Script 的  Code.gs  中，必須確定有這行代碼：
 .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL) 
*（這是允許別人「嵌入」你網頁的通行證，之前的代碼我已經幫你寫進去了。）*

2. 
**管理部署**：
每次修改  Code.gs  或 GAS 內的  index.html （例如加入氣象功能）後，你必須：

- 點擊 **「部署」 > 「管理部署」**。
- 點擊 **鉛筆圖示（編輯）**。
- 版本選擇 **「新版本」**。
- 點擊 **「部署」**。
- **使用新的  /exec  網址** 更新到 Netlify 的這個  index.html  裡。
3. 
**Netlify 更新**：
如果你之後想換網址或代碼，只需把新的資料夾再次「拖拽」進 Netlify 的 Deploy 區域，它就會自動更新。

---

**下一步：**
當你把這個檔案丟上 Netlify 並設定好  xxx.netlify.app  之後，請試著在手機上開啟它。

**您可以順利在頁面上方看到即時的「環境溫濕度」了嗎？如果有顯示「無法取得氣象數據」，通常是 API Key 的權限尚未生效，我們再來除錯！**
