# 📚 SCA 考官理論：沒有看到完整的簡報，而且要可以讓我下載的google簡報

## 📋 對話理論筆記
抱歉讓您困惑了。作為 AI，我無法直接建立一個檔案（如 .pptx 或 Google Slides 連結）讓您點擊下載。但我可以使用 **「Google Apps Script」** 的方式，幫您**自動生成**這份簡報到您的 Google 雲端硬碟中。

您不需要懂程式碼，只需要跟著以下 **3 個步驟** 操作，這份完整的 10 頁簡報就會自動出現在您的 Google Drive 裡。

---

### 🚀 自動生成 Google 簡報的步驟：

#### 第一步：開啟 Google Apps Script

1. 登入您的 Google 雲端硬碟 (Google Drive)。
2. 點擊左上角的 **「+ 新增」** > **「更多」** > **「Google Apps Script」**。
*(如果沒看到，請點「連結更多應用程式」搜尋 Apps Script)*

#### 第二步：貼上程式碼

1. 進入編輯器後，將原本的內容刪除。
2. **複製下方完整的程式碼**，貼入編輯器中。
3. 點擊上方的 **「儲存」** (磁碟片圖示)，專案名稱可隨意取 (例如：咖啡簡報生成器)。

 function createCoffeePresentation() {
  // 1. 建立簡報
  var deck = SlidesApp.create("咖啡深夜食堂：豆種、製程與化學分子的感官地圖");
  var slides = deck.getSlides();
  
  // 刪除預設的第一張空白投影片，保持整潔
  if (slides.length > 0) {
    slides[0].remove();
  }

  // --- 設定樣式變數 ---
  var bgColor = "#2B2B2B"; // 深灰色背景 (深夜食堂風)
  var titleColor = "#FFD700"; // 金色標題
  var bodyColor = "#FFFFFF"; // 白色內文

  // --- 輔助函式：新增投影片 ---
  function addSlide(titleText, bodyItems) {
    var slide = deck.appendSlide(SlidesApp.PredefinedLayout.TITLE_AND_BODY);
    slide.getBackground().setSolidFill(bgColor);
    
    // 設定標題
    var title = slide.getShapes()[0];
    title.getText().setText(titleText);
    title.getText().getTextStyle().setForegroundColor(titleColor).setFontSize(36).setBold(true);
    
    // 設定內文
    var body = slide.getShapes()[1];
    var textRange = body.getText();
    
    var content = bodyItems.join("\n");
    textRange.setText(content);
    textRange.getTextStyle().setForegroundColor(bodyColor).setFontSize(20);
    
    // 設定行距
    var paragraphStyle = textRange.getParagraphStyle();
    paragraphStyle.setLineSpacing(150);
  }

  // --- 輔助函式：新增封面 ---
  function addCoverSlide(mainTitle, subTitle, author) {
    var slide = deck.appendSlide(SlidesApp.PredefinedLayout.TITLE_AND_SUBTITLE);
    slide.getBackground().setSolidFill(bgColor);
    
    var title = slide.getShapes()[0];
    title.getText().setText(mainTitle);
    title.getText().getTextStyle().setForegroundColor(titleColor).setFontSize(50).setBold(true);
    
    var sub = slide.getShapes()[1];
    sub.getText().setText(subTitle + "\n\n" + author);
    sub.getText().getTextStyle().setForegroundColor(bodyColor).setFontSize(24);
  }

  // --- 開始生成內容 ---

  // Slide 1: 封面
  addCoverSlide(
    "咖啡深夜食堂",
    "豆種、製程與化學分子的感官地圖\n一場關於變因控制與風味化學的實證研習",

    "3. 紅絲絨肯亞 (水洗) = 磷酸的味覺具象化 (H3PO4)",
    "4. 葉門摩卡 (日曬) = 極低水活性乾燥 (Aw < 0.6)"
  ]);

  // Slide 3: 實驗模組 A
  addSlide("⚗️ 實驗模組 A：製程 (Process)", [
    "【控制變因】水洗 vs. 日曬",
    "",
    "☕ 杯測對照組：",
    "   • 藝伎組：露西水洗 vs. 露西日曬",
    "   • 衣索比亞組：水洗 TOH vs. 花蝶日曬",
    "",
    "🧪 科學探究點：",
    "   • 國小自然：黏果膠層 (Mucilage) 的微生物發酵作用",
    "   • 國中理化：滲透壓與物質擴散 (細胞壁破裂後的物質遷移)"
  ]);

  // Slide 4: 實驗模組 B
  addSlide("🌍 實驗模組 B：風土 (Terroir)", [
    "【控制變因】產地與土壤條件",
    "",
    "☕ 杯測對照組：",
    "   • 酸質代表：紅絲絨肯亞 (強烈檸檬/烏梅酸)",
    "   • 乾燥代表：葉門摩卡日曬 (乾燥氣候香料味)",
    "",
    "🧪 科學探究點：",
    "   • 化學：有機酸 vs 無機酸 (肯亞火山土的磷酸根離子)",
    "   • 地科：氣候乾燥度導致的低水活性 (Aw) 與保存機制"
  ]);

  // Slide 5: 實驗模組 C
  addSlide("🦠 實驗模組 C：現代發酵 (Fermentation)", [
    "【控制變因】發酵方式 (厭氧 vs 特殊處理)",
    "",
    "☕ 杯測對照組：",
    "   • 莫札特 (葡萄乾蜜處理)",
    "   • 豔夏花荔 (雙重厭氧)",
    "",
    "🧪 科學探究點：",
    "   • 有機化學：酯化反應 (酸 + 醇 → 酯 + 水)",
    "   • 生物：酵母菌的厭氧呼吸 (C6H12O6 → 2C2H5OH + 2CO2)"

  ]);

  // Slide 8: AI 教案工坊 (自然)
  addSlide("🌱 AI 課程設計：國小自然篇", [
    "Prompt 示範指令：",
    "「比較『肯亞水洗』與『葉門日曬』，設計高年級『食農教育與植物構造』教案。」",
    "",
    "課程重點產出：",
    "1. 利用咖啡果實構造 (果皮/果肉/種子) 解釋處理法差異。",
    "2. 觀察豆子外觀 (銀皮/皺縮度) 推測處理法。",

  // Slide 9: 講師小抄
  addSlide("📝 講師備課小抄 (Cheat Sheet)", [

#### 第三步：執行並取得簡報

1. 程式碼貼好後，點擊工具列上的 **「執行」** (Play 按鈕，三角形圖示)。
2. 第一次執行會跳出「審查權限」視窗，請點選 **「審查權限」** > 選擇您的帳號 > **「進階」** > **「前往... (不安全)」** (這是Google對自寫腳本的標準警示，因為是您自己執行的，所以是安全的) > **「允許」**。
3. 執行完畢後（下方執行紀錄顯示「執行完畢」），回到您的 **Google 雲端硬碟首頁**。
4. 您會看到一個名為 **「咖啡深夜食堂：豆種、製程與化學分子的感官地圖」** 的 Google 簡報檔案。
5. 打開該檔案，您可以：

- 點擊 **「檔案」** > **「下載」** > **「Microsoft PowerPoint (.pptx)」**。
- 或者直接在 Google Slides 上進行編輯與播放。
