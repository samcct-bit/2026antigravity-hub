# 📚 SCA 考官理論：好的

## 📋 對話理論筆記
太棒了！身為考官，我最欣賞的就是「實踐」。理論只是基礎，唯有透過系統化的實驗，你才能真正掌握水溫、研磨度與萃取率之間的動態平衡。

這份 **「SCA 專業沖煮實作練習表」** 是為了讓你進行 **A/B Testing**（對比測試）而設計的。透過固定變數，你將能精確體會處理法對風味的影響。

---

## ☕️ SCA 專業手沖實作練習表：處理法對照組

### 實驗前準備（固定變數）

- **濾杯：** V60 或同類型錐形濾杯
- **濾紙：** 經過熱水沖洗（去除紙味並預熱）
- **粉重：** $20\text{g}$
- **總水量：** $300\text{g} - 320\text{g}$ (依粉水比調整)
- **水質：** 符合 SCA 標準（總硬度 $50-175\text{ppm}$，鹼度 $40-75\text{ppm}$）

---

### 第一階段：水洗處理法 (Washed Process)

> 
**教學目標：** 追求「極致乾淨度」與「線性酸質」。

| 參數項目 | 建議設定 | 你的實測紀錄 |
| --- | --- | --- |
| 研磨度 | 中偏細 (EK43 約 8.5-9.0) |  |
| 水溫 | $92^\circ\text{C} - 94^\circ\text{C}$ |  |
| 粉水比 | $1:16$ (粉 $20\text{g}$ / 水 $320\text{g}$) |  |
| 手法建議 | 三段式注水： 悶蒸 30s $\rightarrow$ 繞圈注水至 200g $\rightarrow$ 中心注水至 320g。 |  |
| 萃取目標 | 總時間：2'15" - 2'40" |  |
| 感官查核 | 具備明亮的柑橘酸、花香、體感輕盈。 |  |

---

### 第二階段：日曬處理法 (Natural Process)

> 
**教學目標：** 追求「甜感與油脂感的平衡」。

| 參數項目 | 建議設定 | 你的實測紀錄 |
| --- | --- | --- |
| 研磨度 | 中度 (比水洗稍粗) |  |
| 水溫 | $90^\circ\text{C} - 92^\circ\text{C}$ |  |
| 粉水比 | $1:15$ (粉 $20\text{g}$ / 水 $300\text{g}$) |  |
| 手法建議 | 分段注水（增加浸泡時間）： 延長悶蒸至 40s，後續維持低水位繞圈。 |  |
| 萃取目標 | 總時間：2'20" - 2'50" |  |
| 感官查核 | 熱帶水果甜感、漿果風味、餘韻帶巧克力感。 |  |

---

### 第三階段：厭氧發酵處理法 (Anaerobic Fermentation)

> 
**教學目標：** 追求「風味複雜度」並「避免過度萃取」。

| 參數項目 | 建議設定 | 你的實測紀錄 |
| --- | --- | --- |
| 研磨度 | 中偏粗 (豆體較鬆，溶解極快) |  |
| 水溫 | $88^\circ\text{C} - 90^\circ\text{C}$ |  |
| 粉水比 | $1:16.5$ (粉 $20\text{g}$ / 水 $330\text{g}$) |  |
| 手法建議 | 溫和注水： 減少繞圈的物理攪動力，利用水流自然滲透，防止細粉堵塞。 |  |
| 萃取目標 | 總時間：2'30" - 3'00" |  |
| 感官查核 | 特殊酒香、肉桂或乳酸感、質地黏稠。 |  |

---

## 🔬 考官級感官檢核 (Calibration)

在品測這三杯咖啡時，請嘗試在 **SCA 評分表** 的思維下回答以下問題：

1. **水洗豆：** 酸質 (Acidity) 是否活潑且不尖銳？
2. **日曬豆：** 甜度 (Sweetness) 是否在溫度下降後依然飽滿？
3. **厭氧豆：** 是否有「過度發酵」的負面醋酸味 (Acetic) 或土腥味？

> 
**講師私房筆記：**
> 如果你在沖煮厭氧豆時發現尾韻出現「乾澀感 (Astringency)」，這通常不是研磨太細，而是發酵物溶解過快導致。**請嘗試將水溫再降低 $2^\circ\text{C}$**，你會發現風味瞬間變得乾淨許多。
