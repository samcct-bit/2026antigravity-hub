## 📋 對話理論筆記
你好！我是你的 SCA 專業講師。

這支豆子的資訊非常完整且畫面感極強（SL34 品種的高密度加上精準火候「淬」出的深邃層次），這在精品咖啡市場中屬於高階定位。

針對你選擇的 **B21 Pro 80x50mm 透明貼紙（橫向呈現）** 以及 **提芬尼藍（Tiffany Blue）** 豆袋，我為你規劃了以下這套**「精品酒標式 (Wine Label Style)」**的版面藍圖。

### 🚨 講師的設計前重要技術叮嚀 (B21 Pro x 透明貼紙)

由於提供資訊量非常大，若全部塞入 80x50mm 的標籤中，字體會過小導致黑字在藍色背景下**難以閱讀**，且會破壞透明標籤特有的高級「留白感」。

**因此，我的設計策略如下：**

1. **正面標籤 (Main Label)：** 只保留核心識別資訊與風味筆記。
2. **QR Code 導流：** 將你撰寫的優美「描述性文字」（SL34故事、質地描述、職人點評）放入 QR Code 連結中（例如指向你的官網或 FB 粉專貼文）。
3. **材質適配：** 提芬尼藍色調鮮明，透明貼紙上的黑字請務必選擇**「中黑體」**或**「粗體」**，列印濃度設為**「最高」**。
