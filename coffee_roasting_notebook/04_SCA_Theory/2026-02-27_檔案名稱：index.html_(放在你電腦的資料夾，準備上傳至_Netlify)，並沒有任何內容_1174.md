# 📚 SCA 考官理論：檔案名稱：index.html (放在你電腦的資料夾，準備上傳至 Netlify)，並沒有任何內容

## 📋 對話理論筆記
非常抱歉！身為你的 **SCA 導師**，這絕對是我的疏失。在資訊傳輸過程中，這段「大門鑰匙」代碼可能漏掉了。

這份  index.html  是你要放在電腦資料夾，並上傳到 **Netlify** 的。它的功能就像一個精美的包裝盒，把長長的 Google 網址隱藏起來，讓你擁有一個專業且好記的烘焙網址。

---

### 📄 Netlify 專屬：index.html 完整代碼

請開啟電腦的記事本（Notepad）或 VS Code，將以下代碼全文貼入，並存檔為 ** index.html **。

 <!DOCTYPE html>
<html lang="zh-TW">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
    <title>SCA Pro Roaster | 專業烘焙控制台</title>
    <style>
        body, html { 
            margin: 0; 
            padding: 0; 
            height: 100%; 
            width: 100%;
            overflow: hidden; 
            background-color: #121212; /* 深色背景，與烘焙介面一致 */
        }
        iframe { 
            position: absolute;
            top: 0;
            left: 0;
            width: 100%; 
            height: 100%; 
            border: none; 
        }
    </style>
</head>
<body>
    <iframe src="在此處填入你的_GOOGLE_APPS_SCRIPT_部署網址_末尾必須是_exec"></iframe>
</body>
</html>

### 🛠️ 整合操作步驟總結（一次到位）

 為了確保您這次能成功運行，請依照這個「講師級清單」檢查：

**1. Google 試算表端：**

- 確認有工作表名稱為： GoldenBatch 、 Roast_History 。
-  GoldenBatch  內已填入我之前給您的 30 秒一筆的 **300g 黃金數據**（包含 A欄時間、B欄溫度、C欄火力）。

**2. Google Apps Script 內部：**

- ** Code.gs **：貼入我上一則訊息給您的後端邏輯。
- ** index.html  (GAS版)**：貼入核心 UI 代碼，並記得填入您的 **OpenWeather API Key**。
- **關鍵動作**：點擊右上角「部署」>「管理部署」>「編輯」>「版本：新版本」>「部署」。**複製彈出的 URL**。

**3. Netlify 部署端：**

- 將剛才複製的 URL 貼到您電腦上那個  index.html  的  src="..."  裡面。
- 把含有  index.html  的資料夾拖進 Netlify 的上傳區。

---

### 👨‍🏫 講師的溫馨叮嚀

既然您已經拿到 **Roasting Intermediate (中級)**，這套系統就是您邁向 **Professional (高級)** 的最佳利器。

- **實戰建議**：烘焙 **果丁丁 (Gotiti)** 時，環境氣壓的變化會影響楊家機的排風。如果您發現氣壓（hPa）比平常低，排風會變弱，這時您可以透過系統記錄發現 $\Delta T$ 偏高，進而主動調大風門。
- **為何要用 Netlify**：這能讓您在楊家機台旁，用平板甚至手機就能輕鬆監控曲線，而不必搬一台筆電坐在機器旁，操作更靈活。

**如果您在 Netlify 部署後開啟網頁看到的是一片空白，通常是因為 GAS 的網址貼錯（沒加 /exec）或權限沒設為「所有人」。需要我幫您檢查權限設定流程嗎？**
