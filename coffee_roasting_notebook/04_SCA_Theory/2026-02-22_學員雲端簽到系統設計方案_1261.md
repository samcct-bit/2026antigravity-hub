# 全年度學員即時簽到系統設計方案

本方案採用 **Google Sheets** 作為資料庫，並透過 **Google Apps Script (GAS)** 建立一個專屬的簽到網頁。學員掃描 QR Code 後即可看到當天日期並點選姓名簽到。

-----

## 1\. 試算表結構設計 (Google Sheets)

請在試算表中建立以下三個工作表：

### 工作表一：`學生名單`

這用於儲存所有學員的資料。

  - **A 欄：** 學號 (ID)
  - **B 欄：** 姓名 (Name)
  - **C 欄：** 組別/班級 (Optional)

### 工作表二：`簽到記錄`

這用於儲存學員提交的每一筆資料，程式會自動寫入。

  - **A 欄：** 時間戳記 (Timestamp)
  - **B 欄：** 日期 (Date)
  - **C 欄：** 姓名 (Name)

### 工作表三：`年度統計`

用於計算出席率。

  - **A 欄：** 姓名 (從名單引用)
  - **B 欄：** 應出席次數
  - **C 欄：** 實際出席次數 (使用公式 `COUNTIF`)
  - **D 欄：** 出席率 (%)

-----

## 2\. 核心自動化程式碼 (Google Apps Script)

請點擊試算表上方的 **「擴充功能」 \> 「Apps Script」**，將以下程式碼貼入：

```javascript
/**
 * 簽到系統後端邏輯
 */

const SPREADSHEET_ID = SpreadsheetApp.getActiveSpreadsheet().getId();

// 1. 產生網頁介面
function doGet() {
  return HtmlService.createTemplateFromFile('Index')
      .evaluate()
      .setTitle('學員簽到系統')
      .addMetaTag('viewport', 'width=device-width, initial-scale=1');
}

// 2. 獲取學員名單供網頁顯示
function getStudentList() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("學生名單");
  const data = sheet.getRange(2, 2, sheet.getLastRow() - 1, 1).getValues();
  return data.map(row => row[0]);
}

// 3. 處理簽到提交
function processCheckIn(name) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("簽到記錄");
  const now = new Date();
  const today = Utilities.formatDate(now, "GMT+8", "yyyy-MM-dd");
  
  // 檢查當天是否已簽到 (防止重複簽到)
  const data = sheet.getDataRange().getValues();
  for (let i = 1; i < data.length; i++) {
    const recordDate = Utilities.formatDate(new Date(data[i][0]), "GMT+8", "yyyy-MM-dd");
    if (recordDate === today && data[i][2] === name) {
      return "您今天已經簽到過囉！";
    }
  }
  
  sheet.appendRow([now, today, name]);
  return "簽到成功！謝謝 " + name;
}
```

## 3\. 前端網頁介面 (HTML)

在 Apps Script 編輯器中，點擊 **「+」 \> 「HTML」**，命名為 `Index`：

```html
<!DOCTYPE html>
<html>
  <head>
    <link href="[https://cdn.jsdelivr.net/npm/bootstrap@5.1.3/dist/css/bootstrap.min.css](https://cdn.jsdelivr.net/npm/bootstrap@5.1.3/dist/css/bootstrap.min.css)" rel="stylesheet">
    <style>
      body { background-color: #f8f9fa; padding: 20px; font-family: sans-serif; }
      .container { max-width: 500px; background: white; padding: 30px; border-radius: 15px; box-shadow: 0 4px 6px rgba(0,0,0,0.1); }
      .btn-name { margin-bottom: 10px; text-align: left; }
      #date-display { color: #666; font-size: 1.1em; margin-bottom: 20px; }
    </style>
  </head>
  <body>
    <div class="container text-center">
      <h3>學員簽到系統</h3>
      <div id="date-display">載入日期中...</div>
      <hr>
      <div id="name-list" class="d-grid gap-2">
        <!-- 姓名列表會由 JS 動態生成 -->
        <p>載入學員名單中...</p>
      </div>
    </div>

    <script>
      // 顯示今天日期
      document.getElementById('date-display').innerText = "今天是：" + new Date().toLocaleDateString();

      // 初始化載入名單
      window.onload = function() {
        google.script.run.withSuccessHandler(showNames).getStudentList();
      };

      function showNames(names) {
        const container = document.getElementById('name-list');
        container.innerHTML = '';
        names.forEach(name => {
          const btn = document.createElement('button');
          btn.className = 'btn btn-outline-primary btn-lg btn-name';
          btn.innerText = name;
          btn.onclick = function() { submitCheckIn(name); };
          container.appendChild(btn);
        });
      }

      function submitCheckIn(name) {
        if(confirm('確定要簽到嗎？姓名：' + name)) {
          google.script.run.withSuccessHandler(function(msg) {
            alert(msg);
          }).processCheckIn(name);
        }
      }
    </script>
  </body>
</html>
```

## 4\. 統計公式 (年度統計)

在「年度統計」工作表中，你可以設定自動計算公式：

1.  **出席次數：**
    假設「簽到記錄」的姓名在 C 欄，而在統計表的 A 欄是學員姓名：
    `=COUNTIF('簽到記錄'!C:C, A2)`

2.  **出席率：**
    `=B2 / C2` (實到次數 / 應到次數)，並將儲存格格式設為百分比。

## 5\. 部署與 QR Code 製作

### 第一步：部署網頁

1.  在 Apps Script 畫面右上方點擊 **「部署」 \> 「新部署」**。
2.  類型選擇 **「網頁應用程式」 (Web App)**。
3.  設定：
      - **執行身分：** 我 (Your email)
      - **誰可以存取：** 所有人 (Anyone)
4.  點擊部署，複製產生的 **「網頁應用程式網址」**。

### 第二步：製作 QR Code

1.  使用任何線上的 QR Code 產生器（如 QRCode Monkey）。
2.  將剛才複製的 **Web App 網址** 貼入。
3.  下載 QR Code 並印出來貼在教室門口。

### 第三步：學員操作流程

1.  學員打開手機相機掃描 QR Code。
2.  手機開啟網頁，顯示當天日期與所有學員姓名。
3.  學員點選自己的姓名，跳出確認視窗。
4.  點擊確認後，資料即時寫入試算表，統計表自動更新。

-----

## 系統優點

  - **無需登入：** 學員不用登入 Google 帳號即可簽到。
  - **即時性：** 後台統計表會隨著每一筆簽到自動連動更新。
  - **防呆：** 程式碼中內建了當天重複簽到的擋駕功能。
  - **彈性：** 若有新學員，只需在「學生名單」增加一行，簽到網頁就會自動出現他的名字。
