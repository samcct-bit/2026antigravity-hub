# 📚 SCA 考官理論：請問這是什麼廠牌型號的烘豆機

## 📋 對話理論筆記
蔡老師您好，我是全方位專家。

根據您提供的照片特徵（木質機身、石英玻璃烘焙室、紅外線/鹵素燈管加熱、獨立的木質冷卻與銀皮收集箱），這台機器的具體廠牌與型號為：
**韓國 BocaBoca 咖啡烘豆機**（BocaBoca Coffee Roaster）。

**合理假設標示：**
因照片中無具體比例尺，**假設**其單次最佳烘焙量約為 150g-200g，該型號為 **BocaBoca 250**；若單次最佳烘焙量可達 400g-500g，則為 **BocaBoca 500**。兩者外觀設計與運作原理高度相似。

根據您的情境設定，以下為該設備的專業工具分析，已整理為可直接複製使用的表格：

| 評估面向 | 詳細說明 |
| --- | --- |
| 功能 | 採用遠紅外線/鹵素燈管為熱源；配備石英玻璃滾筒進行翻攪；具備獨立的排風管、冷卻風扇與銀皮收集箱。 |
| 優點 | 1. 全視覺化烘焙：透明玻璃滾筒讓豆色變化一目了然。2. 熱源穿透性佳：紅外線加熱有助於咖啡豆心均勻熟透。3. 美學設計：原木外觀極具質感，適合居家擺設且運作噪音相對較小。 |
| 限制 | 1. 缺乏數據化介面：原廠無內建豆溫/爐溫探測棒，無法直接連動 Artisan 等專業烘豆軟體記錄曲線。2. 風門控制受限：排風與銀皮收集系統為獨立外接，無法在烘焙過程中精準微調風門（Damper）來控制對流熱。3. 蓄熱性差異：玻璃材質蓄熱力低於傳統碳鋼或鑄鐵鍋，烘焙節奏較易受環境室溫影響。 |
| 使用門檻 | 低。操作直觀，非常適合依賴視覺（看豆色）與聽覺（聽一爆、二爆音）的初學者。 |
| 教學應用 | 極佳的課堂示範教具。無論是自然科學課程或社團活動，學生皆可無死角地觀察生豆從脫水、梅納反應、焦糖化到爆裂的完整物理與化學變化。 |
| 適合情境 | 居家少量自烘、咖啡社團初階教學展示、重視生活儀式感及視覺體驗的咖啡愛好者。 |
| 替代方案 | 1. 若追求數據化與精準控制：建議升級為 Kaleido 狙擊手系列 或 Aillio Bullet R1。2. 若追求極致輕量與純直火體驗：可考慮 KAKU 鋼絲網手搖烘豆器 或 陶鍋。 |
