# 📚 SCA 考官理論：修改：我想要將 index.html 匯出到其他網站，讓它可以回來讀取寫入目前的 Google Sheets，請修改目前

## 📋 對話理論筆記
要將 Google Apps Script (GAS) 作為後端 API 供外部網站（如 GitHub Pages、Wordpress 或個人網頁）呼叫，主要的改變在於將原本內建的  google.script.run  替換為標準的 ** fetch  API**。

以下是修改後的程式碼，分為後端 GAS 與前端 HTML 兩個部分：

### 第一步：修改後端  Code.gs 

在 GAS 中，外部請求會透過  doGet （讀取留言）與  doPost （寫入留言）來處理。我們需要改用  ContentService  回傳 JSON 格式。

 // 1. 處理讀取留言 (GET)
function doGet(e) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheets()[0];
  const data = sheet.getDataRange().getValues();
  
  data.shift(); // 移除標題列
  const messages = data.reverse().map(row => ({
    id: row[0],
    time: Utilities.formatDate(new Date(row[1]), "GMT+8", "yyyy-MM-dd HH:mm"),
    name: row[2],
    content: row[4],
    emoji: row[5]
  }));

  // 回傳 JSON 給外部網站
  return ContentService.createTextOutput(JSON.stringify(messages))
    .setMimeType(ContentService.MimeType.JSON);
}

// 2. 處理寫入留言 (POST)
function doPost(e) {
  try {
    // 取得外部傳來的參數
    const params = e.parameter;
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const sheet = ss.getSheets()[0];
    const id = sheet.getLastRow();
    const timestamp = new Date();
    
    sheet.appendRow([
      id, 
      timestamp, 
      params.name, 
      params.email, 
      params.content, 
      params.emoji
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({ status: 'success', message: '留言成功！' }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: 'error', message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

### 修改重點：

1. **CORS 解決方案**：外部網站無法直接存取 Google 資源，但 GAS 的 Web App 只要回傳  ContentService  並將執行身分設為「我」，所有人皆可存取， fetch  就能順利運作。
2. **API 模式**：

-  doGet ：當你開啟網頁或  fetch(URL)  時，它會回傳目前的留言清單。
-  doPost ：當表單送出時，透過  URLSearchParams  將資料傳給 GAS 進行寫入。
3. **安全性**：由於 GAS 網址是公開的，建議在正式環境中加入簡單的驗證碼或 token，防止機器人惡意灌票。

 現在你可以將這段  index.html  程式碼複製到任何地方（例如你的桌面點開、或是上傳到其他網頁伺服器），它都能與原本的 Google 試算表同步運作了！
