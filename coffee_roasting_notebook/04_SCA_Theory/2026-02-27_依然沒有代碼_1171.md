# 📚 SCA 考官理論：依然沒有代碼

## 📋 對話理論筆記
真的很抱歉，讓你感到困擾了！身為講師，我會確保這次你一定能看到代碼。如果代碼區塊在你的介面上還是消失，這可能是顯示系統的特殊狀況，我會嘗試用最清晰的方式呈現。

這份代碼是你要放在電腦資料夾，準備上傳到 **Netlify** 的「外殼」檔案。

---

### 📄 Netlify 專用：index.html 完整代碼

請複製以下內容，並在電腦上存檔為 ** index.html **：

 <!DOCTYPE html>
<html lang="zh-TW">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no">
    <title>SCA Pro Roaster | 專業烘焙控制台</title>
    <style>
        body, html { 
            margin: 0; 
            padding: 0; 
            height: 100%; 
            width: 100%;
            overflow: hidden; 
            background-color: #121212; 
        }
        iframe { 
            position: absolute;
            top: 0;
            left: 0;
            width: 100%; 
            height: 100%; 
            border: none; 
        }
    </style>
</head>
<body>
    <iframe src="在此處替換為您的_GAS_部署網址_末尾必須是_exec"></iframe>
</body>
</html>
  

---

### 🛠️ 為什麼你看不到代碼？（除錯檢查）

 如果上面的框框還是空的，這是我最後的「手動對策」，請注意以下標記：

1. **檔案開頭** 是  <!DOCTYPE html> 。
2. **檔案結尾** 是  </html> 。
3. 中間最關鍵的一行是  <iframe src="你的網址"></iframe> 。

---

### 👨‍🏫 部署到 Netlify 的「零失敗」步驟

1. **建立資料夾**：在桌面新增一個資料夾，命名為  MyRoasterApp 。
2. **放入檔案**：將上面的代碼存成  index.html  放入該資料夾。
3. **填入網址**：記得把  src  後面那串中文換成你在 Google Apps Script **「管理部署」** 拿到的 **網頁應用程式網址**（必須是  /exec  結尾）。
4. **拖拽上傳**：打開  Netlify 部署頁面 ，直接把整個  MyRoasterApp  **資料夾** 抓進去網頁中心。

### 💡 講師最後的叮嚀

烘焙 **果丁丁 (Gotiti)** 或是 **莫札特 (Mozart)** 時，環境濕度的數據對楊家機的排風影響很大。如果你的 Netlify 網址順利跑起來了，頁面上方應該會出現綠色的氣象資訊。
