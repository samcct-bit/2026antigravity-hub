# 📚 SCA 考官理論：不同咖啡飲品的種類

## 📋 對話理論筆記
咖啡飲品的種類繁多，最常見的分類方式是根據**沖煮基底**（如義式濃縮或手沖）以及**添加物比例**（如牛奶、奶泡、巧克力或水）來區分。

以下為您整理的常見咖啡飲品分類指南：

---

## 1. 義式濃縮系列 (Espresso Based)

這類咖啡以「義式濃縮咖啡」為靈魂基底，透過不同的牛奶與奶泡比例變化出多種口感。

| 咖啡名稱 | 組成比例 (咖啡 : 牛奶 : 奶泡) | 口感特色 |
| --- | --- | --- |
| 義式濃縮 (Espresso) | 1 : 0 : 0 | 極致濃郁，帶有咖啡油脂 (Crema)，是所有義式咖啡的基礎。 |
| 美式 (Americano) | 濃縮咖啡 + 大量熱水 | 口感清爽，最能表現咖啡豆原本的甘苦。 |
| 拿鐵 (Caffè Latte) | 1 : 4 : 微量 | 牛奶比例最高，口感滑順充滿奶香，適合初學者。 |
| 卡布奇諾 (Cappuccino) | 1 : 1 : 1 | 奶泡厚實綿密，咖啡感比拿鐵重，層次分明。 |
| 澳式白咖啡 (Flat White) | 雙份濃縮 : 2 : 極薄奶泡 | 奶泡極薄，強調咖啡的醇厚度與絲滑感。 |
| 摩卡 (Mocha) | 濃縮 + 牛奶 + 巧克力醬 | 苦甜交織，通常會加鮮奶油，像甜點般的咖啡。 |
| 瑪奇朵 (Macchiato) | 濃縮 + 一點點奶泡 | 「點綴」之意，保留濃縮的強烈但多了一抹奶香。 |

---

## 2. 黑咖啡與慢速萃取系列

不加入牛奶，直接品嚐咖啡豆產地風味的飲品。

- **手沖咖啡 (Pour Over)：** 使用濾紙過濾，風味最純淨、層次感最明顯，能喝到花果香、酸甜感。
- **冷萃咖啡 (Cold Brew)：** 用冷水長時間浸泡萃取，酸度與苦澀味大幅降低，口感極其滑順、甘甜。
- **冰滴咖啡 (Ice Drip)：** 以冰水緩慢滴濾，風味濃郁且帶有發酵後的酒香。

---

## 3. 特色與創意咖啡

- **西西里咖啡 (Espresso Romano/Lemon Coffee)：** 濃縮咖啡加入檸檬汁與糖（有時加汽水），酸甜清爽，是夏季首選。
- **阿法奇朵 (Affogato)：** 在香草冰淇淋上淋上一份熱騰騰的義式濃縮，既是咖啡也是甜點。
- **維也納咖啡 (Vienna Coffee)：** 黑咖啡上覆蓋厚厚的冰冷鮮奶油，體驗冷熱交替的口感。
- **髒咖啡 (Dirty Coffee)：** 在冰冷的鮮奶上直接萃取熱濃縮，不攪拌，感受由濃到淡、由熱到冷的層次變化。

---

## 選擇建議

- **想提神但怕苦：** 選擇 **拿鐵** 或 **摩卡**。
- **想品嚐咖啡豆原始風味：** 選擇 **手沖** 或 **美式**。
- **喜歡濃厚、分量小：** 選擇 **卡布奇諾** 或 **馥芮白 (Flat White)**。
- **夏天想清爽解膩：** 選擇 **西西里** 或 **冷萃咖啡**。
