# 📚 SCA 考官理論：請幫我搜尋宮古島七月浮潛推薦景點、行程、浮潛嚮導、行程預約網站

## 📋 對話理論筆記
宮古島的七月是浮潛的黃金季節，海水透明度極高且氣候溫暖。以下為您整理的推薦景點、行程規劃、嚮導建議及預約網站：

### 1. 推薦浮潛景點

- **八重干瀨 (Yabiji)：** 日本最大規模的珊瑚礁群，被譽為「宮古藍」的極致。需搭船前往，能見度極高，適合觀賞壯麗珊瑚與熱帶魚。
- **中之島海灘 (Nakanoshima)：** 位於下地島，有「天然水族館」之稱。水域較淺且平穩，珊瑚礁緊鄰岸邊，非常適合親子和初學者。
- **新城海岸 (Aragusuku)：** 這裡以海龜與小丑魚（尼莫）著稱，海灘設施完善，適合岸潛。
- **保良泉（南瓜洞）：** 需隨嚮導浮潛進入海蝕洞，內部有壯觀的南瓜形鐘乳石，是結合探險與浮潛的獨特點。
- **青之洞窟（Sapphire Cave）：** 位於伊良部島，陽光折射出夢幻藍光，是宮古島超人氣的神秘潛點。

### 2. 建議行程安排

七月日間炎熱，建議將水上活動安排在上午或下午三點後：

- **方案 A (半日精華)：** 上午前往 **八重干瀨** 搭船浮潛（約 3-4 小時），下午回市區休息或前往伊良部大橋看海。
- **方案 B (生態探險)：** 上午前往 **南瓜洞** 探險＋浮潛，中午在附近用餐，傍晚去 **與那霸前濱海灘** 漫步。
- **方案 C (悠閒岸潛)：** 整日待在 **中之島** 或 **新城海岸**，在淺灘處自由尋找海龜與尼莫。

### 3. 浮潛嚮導推薦

宮古島有許多專業經營團隊，部分提供中文或英文服務：

- **宮古島 ADVENTURE PiPi：** 大規模營運商，提供海龜浮潛、南瓜洞、SUP 等多樣化行程，通常包含照片拍攝。
- **go2miyako：** 提供八重干瀨專業導覽，服務細膩，適合想深度體驗珊瑚礁的旅客。
- **Miyako-Island Style (中日文服務)：** 若擔心語言問題，可搜尋提供**中文潛導**的店家（如透過石垣島旅遊平台轉介的宮古島行程），這對溝通安全守則更有保障。

### 4. 行程預約網站

建議提早線上預約，尤其是七月旺季：

- **Klook / KKday：** 介面直觀，有大量中文評論參考，適合預訂海龜浮潛或 SUP combo 行程。
- **ActivityJapan (繁體中文版)：** 日本在地最大的體驗預訂站，常有早鳥折扣或特殊行程（如無人機攝影）。
- **Tabirai (沖繩活動預約)：** 針對租車與水上活動有許多在地店家的彙整。

**小提醒：** 七月是颱風季，預約時請確認店家的**取消政策**。此外，由於您是咖啡愛好者，浮潛後可前往市區的特色咖啡店（如 *Slow Coffee* 或 *Utatane Coffee*），享受島上的精品咖啡時光。
