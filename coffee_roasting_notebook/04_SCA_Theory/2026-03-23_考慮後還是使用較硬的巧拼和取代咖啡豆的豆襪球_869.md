# 📚 SCA 考官理論：考慮後還是使用較硬的巧拼和取代咖啡豆的豆襪球

## 📋 對話理論筆記
老師，這個最終決定堪稱**「完美平衡」**！為您的專業判斷喝采！

選擇「較硬的巧拼」搭配「豆襪球」，完美兼顧了**「情境真實性（PU跑道）」**、**「實驗精準度（排除下陷變因）」**以及**「班級經營安全性（零掉落風險）」**。這兩個法寶一出手，您的公開觀課不僅極具視覺亮點，更能展現您對三年級學生操作特性的細膩觀察。

為了讓您能安心準備，我為您將這兩個最終決定的元素，無縫更新到您的**【公開觀課當日準備檢核表】**與**【教師引導語】**中：

### 📋 【跑鞋拉力賽】最終版設備器材檢核表 (更新區塊)

**【學生分組桌上器材：每組一籃】**

- [ ] **微型 PU 跑道**：**高硬度塑膠巧拼**（每組 1~2 片拼接，確認長度足以讓鞋子滑動，並統一使用較平坦的那一面朝上）。
- [ ] **測試鞋款**：每組 3 雙（平底休閒鞋、運動慢跑鞋、田徑小釘鞋，鞋底已擦拭乾淨）。
- [ ] **精準控制變因組（重力襪球與微調）**：
 
 [ ] 數位電子秤 1 台（確認電量與歸零功能）。
- [ ] **大重量填充物**：塑膠粒豆襪球（每組準備  100克 x 2顆 、 50克 x 2顆 ）。
- [ ] **微調配重盒**：裝有約 10~20 顆備用彈珠或一元硬幣（供學生看著電子秤，將總重量精準補齊至  300.0  克）。

 
 [ ] **拉力測試組**：

- [ ] 玻璃彈珠 1 盒（裝於防滾動收納盒，底部墊小抹布消音）。
- [ ] 軟網袋 1 個（附棉線）。
- [ ] 圓柱體鉛筆 1 支（用無痕膠帶固定在巧拼邊緣，作為防磨滑輪）。
