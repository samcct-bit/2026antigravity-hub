## 🌟 「的」和「得」的小祕訣

### 1. 「的」的用法：名詞的好朋友

「的」通常放在**形容詞**後面，或是用來表示**誰的東西**。

- **公式：** 形容詞 + **的** + 名詞
- **例子：** 美麗**的**風景、我**的**書、慢慢**的**走。
- **口訣：** 看到後面的字是「東西（名詞）」，用「的」就對了！

### 2. 「得」的用法：動作的評分員

「得」通常放在**動詞**或**形容詞**後面，用來形容那個動作「做得怎麼樣」。

- **公式：** 動詞 + **得** + 形容詞
- **例子：** 跑**得**快、笑**得**很開心、美**得**發泡。
- **口訣：** 動作做完「得」幾分？後面接著形容詞！

 <!DOCTYPE html>
<html lang="zh-Hant">
<head>

        button { font-size: 1em; padding: 10px 20px; margin: 5px; cursor: pointer; border: none; border-radius: 5px; background-color: #4CAF50; color: white; }
        button:hover { background-color: #45a049; }
        #result { margin-top: 20px; font-weight: bold; font-size: 1.1em; }
    </style>

<body>
    <div class="card">
        <h1>的 vs 得 挑戰賽</h1>
        <div id="quiz">
            <p class="question" id="qText">1. 王獻之寫____字，跟人一樣高。</p>
            <button onclick="check('的')">的</button>
            <button onclick="check('得')">得</button>
        </div>
        <p id="result"></p>
        <button id="nextBtn" style="display:none; background-color: #2196F3;" onclick="nextQ()">下一題</button>
    </div>

    <script>
        const questions = [
            { q: "王獻之寫____字，跟人一樣高。", a: "的" },
            { q: "毛筆被獻之牢牢____抓在手裡。", a: "的" },
            { q: "你寫字時，筆握____牢。", a: "得" },
            { q: "大家讚美他寫的字和父親一樣____好。", a: "得" },
            { q: "美麗____風景就在鹿谷。", a: "的" }
        ];
        let current = 0;

        function check(ans) {
            const res = document.getElementById('result');
            if (ans === questions[current].a) {
                res.innerHTML = "✅ 太棒了！答對囉！";
                res.style.color = "green";
                document.getElementById('nextBtn').style.display = "inline-block";
            } else {
                res.innerHTML = "❌ 再想想看，這個字後面接的是什麼？";
                res.style.color = "red";
            }
        }

        function nextQ() {
            current = (current + 1) % questions.length;
            document.getElementById('qText').innerHTML = (current + 1) + ". " + questions[current].q;
            document.getElementById('result').innerHTML = "";
            document.getElementById('nextBtn').style.display = "none";
        }
    </script>
</body>
</html>

## 🌟 「的」和「得」的分身術

### 1. 「的」：東西的好朋友

「的」通常出現在「東西（名詞）」的前面，用來形容它是什麼樣的，或是誰的。

- **口訣：** 形容詞 ＋ **的** ＋ **東西（名詞）**
- **課文例子：**
 
 聰明**的**小孩（形容小孩）
- 王羲之**的**家（誰的家）
- 拔不起來**的**筆（形容那枝筆）

 
 

### 2. 「得」：動作的評分員

「得」通常跟在「動作（動詞）」的後面，用來形容這個動作「做得怎麼樣」。

- **口訣：** 動作（動詞） ＋ **得** ＋ **形容詞**
- **課文例子：**
 
 筆握**得**牢（形容「握」這個動作）
- 寫**得**一模一樣（形容「寫」的狀態）
- 學**得**好用心（形容「學」的情形）

## 💻 互動練習網頁代碼

你可以將以下代碼存成  .html  檔案（例如： quiz.html ），用電腦瀏覽器打開，就可以讓小朋友進行互動測驗了！

 <!DOCTYPE html>
<html lang="zh-Hant">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>「的」與「得」互動挑戰</title>
    <style>
        body { font-family: "Microsoft JhengHei", sans-serif; background: #FFF9E3; text-align: center; padding: 20px; }
        .container { background: white; border-radius: 20px; padding: 30px; box-shadow: 0 8px 15px rgba(0,0,0,0.1); display: inline-block; max-width: 400px; width: 90%; }
        h1 { color: #FF8C00; font-size: 1.8em; }
        .question { font-size: 1.3em; margin: 20px 0; color: #333; line-height: 1.6; }
        .btn-group { display: flex; justify-content: space-around; }
        button { font-size: 1.2em; padding: 15px 30px; cursor: pointer; border: none; border-radius: 10px; transition: 0.3s; width: 40%; }
        .btn-de1 { background-color: #FFD700; color: #555; }
        .btn-de2 { background-color: #90EE90; color: #555; }
        button:hover { opacity: 0.8; transform: scale(1.05); }
        #feedback { margin-top: 20px; font-weight: bold; font-size: 1.2em; min-height: 1.5em; }
    </style>
</head>
<body>
    <div class="container">
        <h1>的 vs 得 挑戰賽</h1>
        <p id="qNum">第 1 題 / 共 5 題</p>
        <div class="question" id="qText">讀書可以讓你懂____道理。</div>
        <div class="btn-group">
            <button class="btn-de1" onclick="check('的')">的</button>
            <button class="btn-de2" onclick="check('得')">得</button>
        </div>
        <p id="feedback"></p>
    </div>

    <script>
        const quizData = [
            { q: "讀書可以讓你懂____道理。", a: "的" },
            { q: "王獻之學____好用心。", a: "得" },
            { q: "這是一場特別____表演。", a: "的" },
            { q: "小綠人邁出不疾不徐____步伐。", a: "的" },
            { q: "我們全家人都感動____說不出話來。", a: "得" }
        ];
        let current = 0;

        function check(userAns) {
            const feedback = document.getElementById('feedback');
            if (userAns === quizData[current].a) {
                feedback.innerHTML = "🌟 答對了！你真棒！";
                feedback.style.color = "#2E8B57";
                setTimeout(nextQuestion, 1200);
            } else {
                feedback.innerHTML = "💡 再想一下，「" + userAns + "」後面的字是動作還是東西？";
                feedback.style.color = "#CD5C5C";
            }
        }

        function nextQuestion() {
            current++;
            if (current < quizData.length) {
                document.getElementById('qNum').innerText = `第 ${current + 1} 題 / 共 ${quizData.length} 題`;
                document.getElementById('qText').innerText = quizData[current].q;
                document.getElementById('feedback').innerText = "";
            } else {
                document.querySelector('.container').innerHTML = "<h1>恭喜挑戰完成！</h1><p>你已經掌握「的」和「得」的用法囉！</p><button onclick='location.reload()' style='width:auto; background:#FF8C00; color:white;'>再玩一次</button>";
            }
        }
    </script>
</body>
</html>
