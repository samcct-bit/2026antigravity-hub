# 📚 SCA 考官理論：請問如何將生成的網址貼到netlify.app生成好記的網址

## 📋 對話理論筆記
這是一個非常聰明的做法！身為 **SCA 講師**，我非常認同將工具「產品化」的思維。Google Apps Script 原生的網址（ script.google.com/... ）確實又長又難記，且在行動裝置上不方便輸入。

要把你的烘焙控制台透過 **Netlify** 轉化為一個好記的網址（例如  my-roasting-pro.netlify.app ），最穩定且簡單的方法是使用 **「Iframe 嵌入法」**。

由於我們之前的  Code.gs  已經加入了  .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL) ，這讓你的 GAS 應用程式具備了被嵌入其他網頁的權限。

以下是手把手的設置步驟：

---

### 第一步：準備 Netlify 專用的前端檔案

在你的電腦桌面建立一個資料夾，命名為  my-roaster 。在資料夾內建立一個名為  index.html  的檔案，並貼入以下代碼：

 <!DOCTYPE html>
<html lang="zh-TW">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>SCA Pro Roasting Master</title>
    <style>
        body, html { margin: 0; padding: 0; height: 100%; overflow: hidden; }
        /* 讓 GAS 控制台填滿整個螢幕 */
        iframe { width: 100%; height: 100%; border: none; }
    </style>
</head>
<body>
    <iframe src="你的_GOOGLE_APPS_SCRIPT_網址_末尾必須是_exec"></iframe>
</body>
</html>
  

---

### 第二步：上傳至 Netlify

1. 登入  Netlify 官網 （可使用 GitHub 或 Google 帳號）。
2. 進入 Dashboard 後，找到 **「Add new site」** 按鈕，選擇 **「Deploy manually」**（手動部署）。
3. 將你剛剛建立的  my-roaster  資料夾（裡面含  index.html ）直接 **拖拽** 到網頁中的上傳框。
4. 等待幾秒鐘，Netlify 會生成一個隨機網址（例如  shiny-cupcake-12345.netlify.app ）。

---

### 第三步：自訂好記的網址名稱

1. 在部署成功的畫面中，點擊 **「Site configuration」** (或 Site settings)。
2. 點擊 **「Domain management」** 分頁。
3. 在 「Domains」 區塊找到你的隨機網址，點擊旁邊的 **「Options」** > **「Edit site name」**。
4. 輸入你想要的名稱，例如： gotiti-roaster-yangchia  或  sca-pro-master 。
5. 點擊 **Save**。現在你可以透過  https://sca-pro-master.netlify.app  直接開啟你的烘焙面板了！

---

### 👨‍🏫 講師級別的細節優化

 將網址縮短後，在楊家機操作現場，我建議你進一步優化體驗：

1. 
**加入主畫面圖示**：
在手機或平板開啟你的 Netlify 網址後，點擊瀏覽器的「分享」按鈕，選擇 **「加入主畫面」**。這會讓你的烘焙控制台看起來就像一個獨立的 App，點擊即開，無需輸入網址。

2. 
**安全性提醒**：
雖然網址變好記了，但別忘了 GAS 的權限設定。如果你在部署時選擇「任何人都可以存取」，那麼只要猜到網址的人都能看到你的烘焙數據。對於個人烘焙室，這通常沒問題，但如果你有商業保密需求，建議在 GAS 端加入一個簡單的密碼驗證視窗。

3. 
**解決「白屏」問題**：
如果嵌入後出現白屏，請回頭檢查  Code.gs  的部署版本。記得每次修改代碼後，都必須 **「管理部署」 > 「編輯」 > 「版本改為新版本」**，並確保網址末尾是  /exec  而非  /dev 。

**恭喜！你現在擁有了一個專屬且專業的烘焙網頁門戶。如果你想更進一步，在 Netlify 的  index.html  加入「烘焙室氣象資訊（溫濕度 API）」，我也能協助你完成！**
